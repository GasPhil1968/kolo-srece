# NIGHT LATCH — Background Art Brief (for room painters)

You are painting original pixel-art backgrounds for a 1991-LucasArts-style noir adventure
(think Monkey Island 2 interiors: rich, hand-crafted, atmospheric, readable). Everything is
generated by Python code in `art/` — no external images, no copied art.

## Read first
* `docs/ROOMS.md` — the room contract (hotspot ids, state objects, points, variants).
* `art/core.py` — ramps (material colour ramps, dark→light, hue-shifted), `Canvas`
  primitives (`rect`, `poly`, `ellipse`, `line`, `put`, `hline`, `vline`), lum helpers
  (`vgrad`, `hgrad`, `radial`, `with_noise`, `noise2`), lights (`add_light`, `glow`,
  `shadow_poly`, `shadow_ellipse`, `light_poly` for light stripes), `render(remap=...)`.
* `art/scene.py` — `Scene` (hotspots, walkable, points, scale, objects, anims, rain, export).
* `art/persp.py` — one-point perspective `Persp` (box(), quad(), floors, walls).
* `art/furniture.py` — shared props (windows, doors, bed, wardrobe, lamps, chair...).
* `art/rooms/hotel_room.py` — **the reference room**. Match its structure and quality.

## Hard rules
1. **Do not edit** shared modules (`core.py`, `scene.py`, `persp.py`, `furniture.py`,
   `chars_*.py`, `preview.py`, `build_all.py`, `rooms/hotel_room.py`). Put your own
   reusable props in `art/props_<yourgroup>.py` and room code in `art/rooms/<id>.py`.
   You may register new ramps from your own module with `core.ramp('<group>_<name>', ...)`
   (prefix names with your group to avoid clashes).
2. Each room module exposes `build() -> Scene`, `VARIANTS = {name: fn(canvas) -> render
   kwargs or None}` and `main()` that calls `sc.export(variants=VARIANTS)` (see reference).
   A variant fn receives a deep copy of the finished canvas: change `c.lights`, `c.ambient`,
   `c.glows`, `c.shade`, or return `{'remap': 'safelight'}`; it may also repaint regions
   (e.g. a window's sky) with the canvas primitives.
3. Hotspot ids, state names, variants and point ids **exactly** as in `docs/ROOMS.md`.
   Every hotspot needs `walk=(x, y)` inside the walkable area (not inside a hole) and
   `face`. Exits are hotspots named `exit_*` placed at doorways/screen edges.
4. Viewport height 144. Width as specified (320 default; 400/480 for scrolling rooms).
5. `sc.scale(yFar, sFar, yNear, sNear)` — the character is ~50 px tall at scale 1.0.
   Size doors/furniture to that: door ≈ 1.15× the person at that depth; chair seat ≈ 0.3×;
   table/counter ≈ 0.45–0.55×. Keep sFar ≥ 0.7.
6. NPC stand points (`*_spot`): leave room for a ~50 px figure. If an NPC stands behind a
   counter/desk, make that counter a static object with a `baseline` (its front floor y)
   greater than the NPC's spot y so the NPC is drawn behind it.
7. Set `sc.meta['floor']` (wood|stone|metal|carpet|tile|grass|water).
8. Build and check: `python3 art/build_all.py <id>` then
   `python3 art/preview.py <id> <states,comma,separated> <variant>` and
   `python3 art/preview.py <id> "" "" --debug` — **open the PNGs with the Read tool and look
   at them**. Iterate until the room looks finished and the debug overlay is correct.

## Style
* Colour noir, not grayscale: night blues and teals, sodium-amber lamplight, red/blue neon,
  sickly greens for institutions, warm wood. Use hue-shifted ramps (cool shadows, warm lights).
* Light design sells the scene: 1–3 key lights (`add_light` + `glow`), emissive sources
  (`emis=1`) for lamps, neon, lit windows; soft pools on floors (`ystretch>1`); shadows under
  furniture (`shadow_poly`/`shadow_ellipse`); venetian-blind stripes with `light_poly`;
  vignette via `c.shade`. Ambient 0.35–0.55.
* Dithering: default partial (0.55). Use `dith=0`–`0.3` for small/crisp details and large
  flat planes that look noisy. Prefer *structured* texture (planks, bricks, tiles, panels,
  mouldings, wallpaper motifs, stains in specific places) over random noise.
* Detail density: 15–30 distinct props per room, environmental storytelling (a coffee ring,
  a stack of files, a cigarette burning, a calendar, a crooked frame, water stains...).
  1-px highlights on edges facing the light; 1-px dark contact lines where objects meet the
  floor/wall.
* Readability: interactive objects slightly higher contrast than the background; nothing
  important lost in black. Leave the walkable floor uncluttered.
* Interiors: frontal back wall + `Persp(bx0, bx1, 0, floor_y, horizon=-40..-80, depth=300..500)`
  for floor and side walls; exteriors may use a lower horizon with layered depth (far
  silhouettes, mid buildings, foreground). Fog layers for harbour scenes.
* Ambient animations via `sc.anim(name, [frame_fn, ...], fps)` (each frame fn draws on a
  clone): ceiling fans, steam, smoke, flickering neon, pendulums, gulls, water shimmer.
  Use `sc.rain(x0,y0,x1,y1, kind='window'|'outdoor')` for rain regions (drawn by the game).
* State objects (`with sc.obj(name, state=True) as cc:` draw on `cc`) for things that appear,
  disappear or change; static occluders with `baseline` for things characters can walk behind.

## Deliverable
Room scripts that build without errors, previews you have inspected, and a short report
listing each room, its variants, any extra hotspots you added (with one-line descriptions)
and anything the game code must know (e.g. where an NPC stands).
